# INSE6180 Project: Association-Rule Mining for Cyber Threat Intelligence

Cyberattacks involve a combination of techniques, but analyzing techniques individually can miss
important patterns. This can be addressed by applying association-rule mining to MITRE
ATT&CK data. Therefore, this project will implement and compare the Apriori and FP-Growth
algorithms under different parameter settings. This will help determine what meaningful
associations between techniques can reveal about attacker behaviour and how the algorithms differ.
